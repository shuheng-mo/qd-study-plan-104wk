# 2x2 矩阵变换可视化项目

## 项目简介

本项目用 C++ 实现了一个完整的 2x2 矩阵类，支持矩阵运算和线性变换。通过可视化单位圆经过各种矩阵变换（旋转、缩放、剪切等）的效果，深入理解线性代数中矩阵变换的几何意义。

## 核心功能

### 1. Matrix2x2 类

完整的 2x2 矩阵类实现，支持以下操作：

- **矩阵乘法**：支持矩阵与矩阵相乘、矩阵与向量相乘
- **基本运算**：行列式、逆矩阵、转置
- **特征分析**：特征值计算
- **打印与输出**：格式化矩阵显示

```cpp
Matrix2x2 A(2, 1, 1, 3);
Matrix2x2 B = A.inverse();
auto det = A.determinant();
auto [e1, e2] = A.eigenvalues();
```

### 2. 变换矩阵工厂函数

预实现的常见线性变换：

- **rotation(theta)**：旋转矩阵（角度为弧度）
- **scaling(sx, sy)**：非均匀缩放
- **uniformScaling(s)**：均匀缩放
- **shearX(k)**：水平剪切
- **shearY(k)**：垂直剪切
- **reflection(theta)**：沿直线反射
- **projection(theta)**：投影变换

### 3. 点集变换与可视化

- **generateUnitCircle(numPoints)**：生成单位圆上的 N 个点
- **transformPoints(points, matrix)**：将矩阵变换应用到点集
- **exportSVG(filename, shapes)**：导出 SVG 格式可视化文件

## 数学背景

### 线性变换的几何意义

2x2 矩阵代表 2D 平面上的线性变换，可以分解为：

1. **旋转**：保持向量长度不变，改变方向
2. **缩放**：改变向量长度，行列式等于面积缩放因子
3. **剪切**：保持面积不变，改变形状
4. **投影**：将空间投影到低维子空间
5. **反射**：沿直线翻转

### 矩阵与变换的关系

- 矩阵列向量：变换后的基向量
- 矩阵行列式：面积缩放因子
- 矩阵迹（tr）：特征值之和
- 矩阵特征值：沿特征向量方向的缩放因子

## 🎯 加分题：为什么神经网络每层都是矩阵乘法？

### 几何直觉

```
输入空间                    输出空间
   ●                           ⬭
  ● ●        W·x + b          ⬭ ⬭
 ● ● ●      ────────→        ⬭ ⬭ ⬭
  ● ●                          ⬭ ⬭
   ●                            ⬭

 数据流形                   变换后的流形
```

### 1. 线性变换的本质

矩阵乘法 **y = Wx** 执行的是：

| 变换类型 | 几何作用 | 神经网络中的意义 |
|---------|---------|-----------------|
| **旋转** | 改变坐标系方向 | 寻找最佳特征方向 |
| **缩放** | 拉伸/压缩各维度 | 强调重要特征，抑制噪声 |
| **剪切** | 倾斜空间 | 创建特征间的相关性 |
| **投影** | 降维 | 提取本质信息 |

**核心洞察**：矩阵乘法是最一般的线性变换，可以组合出任何"保持直线和原点"的空间变形。

### 2. 为什么需要线性 + 非线性的交替？

```
              线性层              非线性层           线性层
输入 ──────→ [矩阵乘法] ──────→ [激活函数] ──────→ [矩阵乘法] ──────→ 输出
             旋转+缩放            折叠空间          再次变换
```

**纯线性的问题**：
$$W_2 \cdot (W_1 \cdot x) = (W_2 \cdot W_1) \cdot x = W_{等效} \cdot x$$

多层纯线性网络等价于单层！无法学习复杂模式。

**非线性激活的作用**：

```
   y                    y
   │    线性            │    ReLU后
   │   ／               │   ／
   │ ／                 │ ／
───┼───── x        ───  ┴──────── x
  ／│                    （折叠负半轴）
／  │
```

激活函数（如ReLU）**折叠**空间，使得后续的线性层能够作用于不同区域。

### 3. 几何视角下的深度学习

**浅层网络**：简单的空间变换

```
     ○ ○          ●●
    ○   ○   →    ●  ●    （只能线性分割）
     ○ ○          ●●
```

**深层网络**：复杂的流形变换

```
第1层: 旋转对齐
第2层: 拉伸分离
第3层: 折叠展开
第4层: 精细调整
   ↓
原本纠缠的数据 → 线性可分的数据
```

**每一层的几何意义**：

1. **矩阵W**：定义变换的方向和强度
2. **偏置b**：平移（打破原点对称性）
3. **激活σ**：非线性折叠（创造新维度效果）

### 4. 数学证明：万能近似定理

**定理**：任何连续函数都可以被有限层的神经网络任意精度逼近。

**几何解释**：

- 每层矩阵乘法 = 空间的线性变形
- 激活函数 = 空间的非线性折叠
- 足够多的"变形+折叠"可以把任何形状的数据流形变成任何其他形状

### 5. 实际例子：图像分类

```
原始像素空间 (高维, 数据纠缠)
         ↓  Conv层 (局部线性变换)
         ↓  ReLU (非线性折叠)
         ↓  ... 重复多层 ...
         ↓
特征空间 (低维, 类别分离)
         ↓  全连接层 (最终线性分割)
         ↓
分类结果
```

**总之**：神经网络 = **可学习的、分层的空间变换机器**

矩阵乘法之所以核心，是因为它是最一般、最高效的线性变换表示，而深度学习的本质就是通过一系列线性变换（矩阵乘法）+ 非线性激活，将复杂的数据流形逐步"解缠"成线性可分的形式。
