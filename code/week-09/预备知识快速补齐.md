  需要掌握：
    • 矩阵维度表示：m×n 表示 m 行 n 列
    • 元素索引：A_ij 或 A[i,j] 表示第 i 行第 j 列的元素
    • 转置符号：A^T 或 A' 表示行列互换

## 最小可用代码模板

```python
import numpy as np

# 创建矩阵

A = np.array([[1, 2], [3, 4]])
B = np.eye(2)  # 2×2 单位矩阵

# 基本操作
A.shape       # 维度 (2, 2)
A.T           # 转置
A @ B         # 矩阵乘法
A * B         # 逐元素乘法（注意区别）
A[0, :]       # 第一行
A[:, 1]       # 第二列
```

## 如何阅读数学公式并转化为代码

  需要掌握：
    • Σ 求和符号 → for 循环或 np.sum()
    • Π 连乘符号 → for 循环或 np.prod()
    • 上下标的含义：x_i 表示向量第 i 个元素
    • 矩阵乘法公式 C_ij = Σ_k A_ik B_kj 的理解

  快速补齐方案：
    • 推荐阅读（20分钟）："Math to Code" 速查对照 <https://mathtocode.com>

  对照示例：
    公式：y = Σ(i=1 to n) x_i · w_i

### 循环写法

    y = 0
    for i in range(n):
        y += x[i] * w[i]

### NumPy 写法

    y = np.dot(x, w)  # 或 x @ w
