Carol若有所思："所以当我们做因子正交化时，本质上就是在找一个新向量，它垂直于现有因子？"

> "对。Gram-Schmidt正交化的核心就是：给定一组线性无关的向量，构造一组正交向量。叉积给出了垂直方向。"

Victor快速写下伪代码：

```python
# 简化版Gram-Schmidt正交化（2D情况）
def orthogonalize(v1, v2):
    # v1 保持不变
    u1 = v1
    # v2 减去在 v1 方向上的投影
    u2 = v2 - (np.dot(v2, u1) / np.dot(u1, u1)) * u1
    # u1 和 u2 现在正交
    return u1, u2

# 在3D情况下，可以用叉积直接构造垂直向量
def orthogonal_vector(v1, v2):
    return np.cross(v1, v2)  # 直接垂直于v1和v2
```

```
2. 工具作用：构造正交基
3. 理论基础：理解高维正交化
```

> "好问题。来，我们从最基础的开始。"

他在白板上写：

```
给定向量v = [x, y]，矩阵A = [a b]
                          [c d]

矩阵乘法 Av = [a b] [x] = [ax + by]
            [c d] [y]   [cx + dy]

这个结果可以写成：
Av = x[a] + y[b]
       [c]   [d]

这意味着什么？
```

Victor停顿了一下，环顾全场：

> "这意味着矩阵A的每一**列**就是对应基向量变换后的结果！第一列是x轴(1,0)变换后的位置，第二列是y轴(0,1)变换后的位置！"

他重重在白板上画了一个图：

```
原始基向量：
e₁ = (1,0) →
e₂ = (0,1) ↑

经过矩阵A变换后：
Ae₁ = (a,c)  ↗
Ae₂ = (b,d)  ↖

任何向量v = xe₁ + ye₂
变换后就是 Av = xAe₁ + yAe₂ = x(a,c) + y(b,d)
```

Alice兴奋地说："所以矩阵的列向量定义了新的坐标系？"

> "exactly！"Victor少见地用了英文，"这就是**线性变换**的本质：把输入空间的基向量映射到输出空间，而保持线性组合关系不变！"

```

- 行列式非零
- 所有列向量线性无关
- 方程组Ax=b有唯一解
- 信息无损失

奇异矩阵：
- 行列式为零
- 至少一个列向量可被其他列表示
- 方程组无解或无穷多解
- 信息有损失（降维）
```

接下来，Victor讲解了**伪逆**（pseudoinverse）：

> "当矩阵不可逆时，我们用伪逆来找到**最佳近似解**。这在过度拟合的线性回归中非常有用。"

接着又写下两行伪代码:

```python
# 普通最小二乘法（可能过拟合）
beta = np.linalg.inv(X.T @ X) @ X.T @ y
# 使用伪逆（更稳定）
beta = np.linalg.pinv(X) @ y
```


## 📒补充说明

事实上，真实的量化研究员和开发不可能因为向量点积这种小事而亏损上千万元，如果这样的话数学基础也太差了， 大一学生都能去做量化。本文故事情节纯属虚构，仅用于说明线性代数在量化金融中的重要性及其核心概念。

本周我们跟随Victor学习了线性代数的核心基础（部分）：

1. 向量的几何直觉
    - **点积的三重意义**：代数定义、几何定义(|a||b|cos(θ))、投影定义
    - **在量化中的应用**：资产相关性、投资组合协同、风险分解

2. 矩阵作为线性变换
    - **核心观点**：矩阵的列向量 = 基向量变换后的位置
    - **常见变换**：旋转、缩放、剪切、投影
    - **在量化中的应用**：神经网络、因子模型、风险映射

3. 线性方程组与逆矩阵
    - **几何视角**：Ax=b 问什么存在向量x使得A把它变换成b
    - **可逆性**：det(A)≠0 ↔ 列向量线性无关 ↔ 有唯一解
    - **伪逆**：当矩阵不可逆时的最佳近似解

4. 行列式与秩
    - **行列式**：变换后体积的缩放比，det(A)=0表示降维
    - **秩**：线性无关列向量的个数，表示有效信息量
    - **在量化中的坑**：协方差矩阵秩亏导致风险低估
